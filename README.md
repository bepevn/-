# CHAIN : 잔광 v5 — BODY CONFIGURATOR

PC용 사이버펑크 2D 액션 프로토타입. 2슬롯 / 9종 사이버웨어 / 8개 변형 구역 / 연습장.

## 배포
ZIP을 풀고 app.py, game.html, requirements.txt, README.md를 GitHub 저장소 최상위에 올리세요. 기존 앱이면 파일을 교체하여 커밋합니다. https://share.streamlit.io/ 에서 해당 저장소와 브랜치를 선택하고 실행 파일을 app.py로 지정합니다. API 키가 필요하지 않습니다.

로컬 실행: pip install -r requirements.txt 후 streamlit run app.py.
game.html 단독으로 브라우저에서 실행할 수도 있습니다. 외부 이미지 / 폰트 / 음악이 없어 HTML 단독 실행은 오프라인에서도 가능합니다. Streamlit Cloud 접속에는 인터넷이 필요합니다.

## v5 변경
- 중간 퇴장: 우측 하단 퇴장 버튼 / 일시정지 메뉴 → 확인 후 메인 메뉴. 취소 가능. 현재 전투 진행은 저장되지 않으며 장착 조합은 유지됩니다.
- 정비실: 슬롯 선택, 모듈마다 2D 외형 미리보기, 장착 여부, 능력 설명. 장착 카드와 고정 하단 출격 영역을 새로 구성했습니다.
- 탈부착: 실제 선택 모듈의 그림을 사용합니다. 기존 모듈 분리, 새 모듈 접근, 장착 위치 체결, 동기화. 팔은 전완 위치, 부츠는 발, 척추형은 몸통, 신경 링크는 목 위치에 연결됩니다. 순정 신체 실루엣과 로봇 정비팔을 사용하는 3.6초 2D 도식 애니메이션입니다. 사실적인 3D 수술 장면은 아닙니다.
- 선택한 두 모듈의 작은 외형도 플레이어에 함께 표시합니다.
- 방어 피막 제거. 기본 평타에 탄환 반사를 적용했습니다.
- 로프 속박과 3종 신규 웨어.
- 구역을 초기화해 진입할 때 상호작용 물체를 발판 위에 무작위 배치. 사망 체크포인트 복귀에서는 배치와 해제 상태를 유지합니다. 지형 자체가 랜덤 생성되는 것은 아닙니다.

## 2슬롯 / 9모듈
슬롯을 고르고 카드를 누르면 장착 시퀀스가 시작됩니다. 선택 슬롯 제거 버튼으로 해제 가능합니다. 중복 장착 불가, 빈 슬롯 허용, 서로 다른 2종 36가지 조합. 전투 중 교체는 불가능하며 구역 사이 정비실 / 연습장 B로 변경합니다.

| 모듈 | 기능 |
|---|---|
| WIRE 로프 런처 | 좌클릭 홀드 이동 로프 / C 속박 |
| ATLAS 강화 의수 | 베기 피해 +25 / 철문 개방 |
| MANTIS 블레이드 암 | 전방 삼중 검격 시각효과와 총 62 피해 / 케이블 절단 |
| GHOST 신경 링크 | 베기를 전방위 반경 225로 확장 / 단말 해킹·발판 생성 |
| 산데비스탄 | R / 4초 동안 적·적 탄환의 시간 흐름 20%, 플레이어 정상 / 재사용 14초 |
| VECTOR 벡터 부츠 | 3단 점프 / 대시 재사용 0.45초 / 추진 패드 사용 |
| TESLA 전격 코일 | T / 반경 300 적에게 55 피해 / 재사용 5초 |
| LEECH 혈액 펌프 | 적에게 실제로 준 피해의 12% 체력 회복. 공격·반사·능력 피해에 적용 |
| PHASE 위상 척추 | 대시 무적 0.45초 / 대시 시작 시 가까운 적에게 추가 피해 30 |

전격 코일은 전력 축전기를 작동시켜 주변 적에게 피해를 줍니다. 혈액 펌프는 생체 포드로 체력 50을 회복합니다. 위상 척추는 전용 게이트로 오른쪽 240px 이동합니다. 이러한 특수 이동은 로프 순간이동 버그와 별개인 게이트 능력입니다.

## 로프 / 속박
- 로프 런처를 장착했을 때만 사용 가능.
- 최대 연결 거리 620px. 실제 거리에서 줄이 감기기 시작하며 캐릭터 좌표를 강제로 끌어당기지 않습니다.
- 장력으로 당기는 로프이며 과도하게 늘어나 700px를 초과하면 자동 해제합니다.
- 다른 모듈은 로프 성능을 바꾸지 않습니다.
- C: 620px 안에서 조준점 가까이의 적을 속박. 일반 적 2.4초, 보스 1.2초, 재사용 5초.
- 속박 중 적의 부유 이동과 공격 타이머가 멈춥니다. 기존에 발사된 탄환은 계속 움직입니다.

## 평타 반사
방어 웨어 없이 모든 조합에서 사용 가능합니다. 우클릭 / J 공격 시 0.16초 동안 전방 반경 175 안의 적 탄환을 반사합니다. 신경 링크 장착 시 전방위로 반사합니다.
반사 탄환은 노란색으로 변하고 조준 방향으로 날아가 적에게 65 피해를 줍니다. 플레이어는 반사 탄환에 맞지 않습니다. 반사 탄환은 산데비스탄 중에도 정상 속도로 이동합니다. 근접 몸통 충돌이나 모든 종류의 공격을 막는 시스템은 아니며, 적 투사체에 적용됩니다.

## 랜덤 상호작용 물체
임무 구역당 철문 / 케이블 / 단말 / 추진 패드 총 10개, 신규 웨어용 물체 3개가 플랫폼 위에 무작위 배치됩니다. 호환 의체를 장착하고 가까이서 F를 누릅니다. 모든 물체는 보너스이며 진행을 강제로 막지 않습니다. 연습장 물체는 테스트 편의를 위해 고정 배치합니다.

## 조작
A/D 이동, W 점프, Q 조준 대시, E 궁극기, R 산데비스탄, C 로프 속박, T 전격 코일, F 상호작용, 좌클릭 홀드 로프, 우클릭/J 베기·반사, P/Esc 일시정지, M 음소거.
연습장: B 정비실, N 초기화. 체력·궁극기 에너지 무제한, 재생 표적 제공. 능력 재사용 시간은 적용됩니다.
게임 화면 클릭으로 키보드 포커스를 주고 영문 입력 상태를 권장합니다.

## 범위와 검사
8개 구역은 기본 구조를 공유하며 지형 높이·색상·적 체력·탄막 난도가 변형됩니다. 로그인·영구 저장·멀티플레이·모바일 전용 조작은 없습니다. 새로고침하면 처음부터 시작합니다.
Python / JavaScript 구문 검사와 가상 Canvas 환경에서 36개 2종 조합, 9종 외형 렌더링과 장착·제거, 플랫폼 위 랜덤 배치와 재부팅 유지, 로프 속박, 기본 공격 반사·반사탄 피해, 퇴장 확인·취소를 검사했습니다. 실제 브라우저 시각·조작 플레이테스트와 Streamlit 실배포는 별도 확인이 필요합니다.

## v5.1 화면 수정
정비실을 화면 높이에 맞춘 세로 구조로 바꿨습니다. 상단 슬롯과 하단 출격 버튼은 고정하고 카드 목록만 스크롤합니다. 미리보기는 object-fit: contain으로 원본 비율을 유지합니다. 좁은 화면은 2열, 낮은 화면은 압축 레이아웃입니다. 실제 브라우저 시각 검증은 별도 필요합니다.
