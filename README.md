# CHAIN v9 — Combat Rebuild
ZIP 내 app.py, game.html, requirements.txt, README.md를 GitHub 최상위에 교체 업로드. Streamlit 메인 파일 app.py.

좌클릭/J 평타 (반사 없음), 우클릭 유지 로프, E 패링 (0.2초 판정, 1.5초 쿨타임), Q 대시, W 점프, C 속박, R 산데비스탄, T 전격. 궁극기 없음.
신규: 팔 TALON 충격 건틀릿, 다리 SPRING 도약 다리, 신경 REFLEX 반사 신경, 코어 REACTOR 가속 심장. 총 13종. 기존 부위별 필터와 드래그 장착 유지. 신규 웨어 외형은 기존 도형 기반 변형입니다.
상호작용 물품 전체 제거 (연습장 포함). 로프 이동 고리와 체크포인트 유지.
12구역 지형은 4가지 배치 규칙으로 재생성. 지상 연속 통로와 상부 발판, 고리, 보스 구역 구성. 구조 패널·경고 줄무늬·지지대 추가. 적은 장갑/코어/무기 도형으로 시각 보강, 5종 패턴 유지. 전면 신규 아트 에셋 제작은 아닙니다.
야간 도시 메인 메뉴 재구성. 외부 이미지 없이 브라우저 Canvas/CSS 사용.
가상 실행: 13웨어 필터, 12구역 생성, 물품 제거, 평타 반사 제거, 전용 패링 검사. 실제 브라우저 시각/실플레이/실배포 미검증.
