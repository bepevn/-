# CHAIN v8 — 부위별 장착 터미널

왼쪽 부위 선택 → 중앙 해당 부위 카드만 표시 → 오른쪽 확대 미리보기 / 설명 → 장착 버튼. 카드 클릭은 상세 보기이며, 드래그 장착과 탈부착 연출도 유지합니다. 팔 3종, 다리 1종, 신경 3종, 코어 2종. 게임 기능은 v7과 동일합니다. 실제 브라우저 시각 확인은 미검증입니다.

# CHAIN v7 — 입력 및 쿨타임

좌클릭 또는 J: 평타 및 탄환 반사 (일반 0.65초 / 맨티스 0.8초 간격).
우클릭 유지: 로프 연결 / 우클릭 해제: 로프 해제.
Q 대시, W 점프, C 속박, R 산데비스탄, T 전격, F 상호작용.
궁극기 E와 에너지 바는 제거했습니다. 하단에 쿨타임 숫자와 진행바를 표시합니다. 미장착 스킬은 비활성 표시됩니다.

배포: 압축을 풀고 app.py, game.html, requirements.txt, README.md를 GitHub 저장소에 교체 업로드. Streamlit 실행 파일은 app.py.
기존 부위별 4슬롯, 12구역, 5종 적, 연습장과 탈부착 시스템은 유지합니다.
브라우저 실플레이와 실배포는 미검증입니다.
